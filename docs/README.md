## 如何使用

1. 将 `Agent_Prompt.md` 直接交给另一位开发 Agent，即可启动完整 App 开发。
2. 开发 Agent 需先阅读 `PRD.md`、`UI_Design_System.md`、`API_Spec.md` 和 7 张截图。
3. 后续阶段完成后，将在此目录补充 Android 项目源码和后端项目源码。

# 大地视频 App 产品需求文档（PRD）

> 版本：v1.0  
> 基于用户提供的 7 张截图还原设计  
> 目标：指导 Android Agent 开发出与截图视觉、交互一致的影视 App

---

## 1. 产品概述

### 1.1 产品名称
大地视频（DDDYMovies / EarthVideo）

### 1.2 产品定位
面向中文用户的移动端影视内容聚合与播放平台，支持电视剧、电影、综艺、动漫、短剧等内容的浏览、搜索、分类筛选和在线播放。

### 1.3 目标用户
- 18-45 岁中文影视内容消费者
- 偏好国产剧、网剧、综艺、动漫
- 需要快速检索、分类找片、榜单发现

### 1.4 核心目标
- 还原截图中的 7 个核心页面 UI 与交互
- 实现完整的内容浏览 → 搜索 → 播放闭环
- 后端使用样例数据，App 可独立运行演示

## 3. 页面详细说明

### 3.1 首页（Home）

**对应截图**：Screenshot_20260817_144633_com.ground.dddymovie.jpg

#### 视觉布局
- 顶部蓝色 Header（渐变或纯色 #3B6EE5）
  - 左侧：搜索框（圆角白色/半透明背景），内嵌放大镜图标 + 占位文字"人鱼"
  - 右侧：历史记录图标、下载图标
- 分类 Tab 栏（Header 下方）：
  - 推荐 | 新剧 | 国外热映 | 电视剧 | 电影 | 综艺
  - 当前选中项底部有蓝色下划线
- 内容区：
  - 双列瀑布流（2 columns），卡片间距约 12dp
  - 每个卡片包含：海报图（圆角 8dp）、标题（1 行）、描述（1 行灰色小字）
  - 海报右上角可能有红色"热播"角标
  - 海报右下角有集数标签（如"更新至16集"、"30集全"）
- 底部固定 TabBar：首页（选中蓝色）、排行、找片、我的

#### 交互
- 点击搜索框 → 跳转搜索页
- 点击历史/下载图标 → 跳转对应页面
- 左右滑动或点击 Tab → 切换内容分类
- 点击影片卡片 → 跳转详情/播放页
- 点击底部 Tab → 切换主页面

#### 数据需求
- GET /api/home/recommend?category={category}&page={page}&size={size}
- 返回影片列表：id, title, description, posterUrl, episodeTag, hotTag, category

### 3.2 搜索页（Search）

**对应截图**：Screenshot_20260817_144637_com.ground.dddymovie.jpg

#### 视觉布局
- 顶部搜索栏：
  - 左侧放大镜 + 输入框（占位符"片名 / 演员 / 导演"）
  - 输入时右侧显示清除按钮（X）
  - 右侧"取消"文字按钮
- 搜索历史：
  - 标题"搜索历史"，右侧垃圾桶清除图标
  - 标签云展示历史关键词（圆角灰色背景）
- 热门搜索：
  - 标题"热门搜索"
  - 双列列表，每项包含：排名/关键词 + "热"/"荐"标签 + 描述小字
- 底部：系统键盘（无需 App 实现）

#### 交互
- 输入关键词 → 实时联想或直接回车触发搜索
- 点击"取消" → 返回上一页
- 点击历史标签 → 直接搜索该关键词
- 点击清除图标 → 清空搜索历史
- 点击热门搜索项 → 触发搜索并跳转结果页

#### 数据需求
- GET /api/search/history
- GET /api/search/hot
- GET /api/search/suggest?keyword={keyword}

### 3.3 搜索结果页（Search Result）

**对应截图**：Screenshot_20260817_144642_com.ground.dddymovie.jpg

#### 视觉布局
- 顶部搜索栏（保留关键词"老九门2"）
- 分类 Tab：全部 | 电视剧 | 电影 | 综艺 | 动漫 | 短剧
- 列表项（纵向单列）：
  - 左侧：海报缩略图（宽高比约 3:4），带红色"热播"角标、集数标签
  - 右侧：
    - 标题（"九门/老九门2"），部分高亮蓝色
    - 类型标签（"电视剧"灰色圆角标签）
    - 地区 · 年份（"中国大陆 · 2026"）
    - 导演：xxx
    - 主演：xxx（最多显示 5 个）
    - 蓝色"立即播放"按钮

#### 交互
- 点击 Tab → 按类型筛选结果
- 点击"立即播放" → 跳转播放页
- 点击列表项 → 跳转详情页（或播放页）
- 上拉加载更多

#### 数据需求
- GET /api/search?keyword={keyword}&type={type}&page={page}&size={size}
- 返回：id, title, highlightTitle, type, region, year, director, actors, posterUrl, episodeTag, hotTag

### 3.7 播放页（Player）

**对应截图**：Screenshot_20260817_144720_com.ground.dddymovie.jpg

#### 视觉布局
- 横屏视频播放器区域（顶部）：
  - 左上角返回箭头 + 标题"重器 1"
  - 右上角 TV 投屏图标、弹幕开关

  - 标题"重器"
  - 右上角"播放源"下拉按钮
  - 评分"0分"、地区、年份、标签、"简介 >"

- 操作栏（横向均分）：
  - 评论（1评论）
  - 收藏（爱心+）
  - 下载
  - 举报/帮助（问号）
  - 分享
- 选集区：
  - 标题"选集" + 右侧"更新至16集 >"
  - 横向数字按钮 1-6，当前选中 1（蓝色边框 + 底部进度条）

- 点击弹幕开关 → 开启/关闭弹幕层

- 点击操作按钮 → 触发对应功能（第一阶段可 Toast 提示）
- 点击选集 → 切换集数

#### 数据需求
- GET /api/movie/detail?id={id}
- GET /api/movie/episodes?id={id}
- GET /api/movie/playUrl?id={id}&episode={episode}&source={source}

```json
  "region": "string",
  "year": 2026,
  "genre": ["string"],
  "director": "string",
  "actors": ["string"],
  "episodeTotal": 30,
  "episodeUpdated": 16,
  "episodeTag": "更新至16集",
  "hotTag": true,
  "rating": 0.0,
  "tags": "国产,剧情",
  "source": "iris 上传",
  "sourceAvatar": "string"

```

```json
{
  "episodeNumber": 1,
  "title": "string",
  "duration": 2762,
  "playUrl": "string",
  "current": true

```

### 4.3 PlaySource（播放源）
```json
{
  "sourceId": "string",
  "sourceName": "string",
  "priority": 1
}
```

```json
{
  "keywords": ["老九门2", "老九门", "九门", "南部档案"]
```

### 4.5 HotSearch（热门搜索）
```json
{
  "keyword": "仙逆",
  "tag": "热",
```

```json
{
  "rank": 1,
  "movieId": "string",
  "movie": { /* Movie 对象 */ }
}
```

## 5. 交互流程

### 5.1 浏览 → 播放流程
```
首页/找片/排行 → 点击影片卡片 → 影片详情（或直接进入播放页） → 选择集数 → 播放
```

### 5.2 搜索流程
```
首页点击搜索框 → 搜索页输入关键词 → 搜索结果页 → 点击立即播放/影片
```

### 5.3 分类找片流程
```
底部 Tab "找片" → 选择类型/地区/年份/排序 → 浏览结果 → 点击影片
```

## 6. 非功能需求

### 6.1 性能
- 列表滑动帧率 ≥ 55fps
- 图片懒加载 + 占位图
- 分页加载，每页 20 条

### 6.2 兼容性
- 最低支持 Android 8.0（API 26）
- 适配全面屏、刘海屏、底部导航手势
- 支持竖屏 + 播放页横屏

### 6.3 安全
- 后端接口允许跨域（CORS）
- 不存储真实用户敏感信息

### 6.4 设计一致性
- 严格还原截图中的蓝色主色调、卡片圆角、标签样式、图标风格
- 中文优先，字体大小层级清晰

## 7. 验收标准

### 7.1 页面完整性
- [ ] 首页：Header、Tab、双列瀑布流、底部导航完整
- [ ] 搜索页：搜索框、历史标签、热门搜索完整
- [ ] 搜索结果页：分类筛选、影片列表、立即播放按钮完整
- [ ] 我的页：用户信息、菜单列表完整
- [ ] 找片页：多维筛选、三列网格完整
- [ ] 排行页：横幅、Tab、带名次列表完整
- [ ] 播放页：播放器、信息区、操作栏、选集完整

### 7.2 功能可用性
- [ ] App 能成功编译运行
- [ ] 能正常浏览首页、找片、排行数据
- [ ] 能搜索并展示结果
- [ ] 能进入播放页并播放测试视频
- [ ] 底部 Tab 导航正常

### 7.3 视觉还原度
- [ ] 主色、布局、字体、间距与截图一致
- [ ] 海报卡片、角标、标签样式正确
- [ ] 播放器界面与截图一致
